## Overview

AMCap provides a straightforward way to work with video input on Windows. It can connect to webcams, capture cards, UVC hardware, and older devices that expose a DirectShow interface, making it suitable for previewing feeds, recording video, streaming output, or saving individual frames.

Version 10.23.300.6 is focused on everyday capture workflows and support for a broad selection of input devices. Audio synchronization, keyboard shortcuts, and dependable source handling make it useful for testing hardware, preparing documentation, sending live output, and performing basic desktop capture tasks.

## Using AMCap

The usual process is to connect a source, verify its preview, and then select the required capture action.

1. Attach a webcam, capture card, or another supported device.
2. Launch AMCap and choose the input you want to use.
3. Select recording, streaming, or snapshot capture.
4. Use the available hotkeys for quicker operation during capture.
5. Check the resulting output and revise the device or audio options if necessary.

A standard session may look like this:

- Open the selected capture source
- Verify that its video feed appears
- Begin recording a clip or longer session
- Stop the capture and save the resulting output
- Take a snapshot whenever a still frame is required

## Frequently Asked Questions

### What hardware can AMCap use?

AMCap is designed for webcams, capture cards, UVC hardware, and other sources compatible with DirectShow.

### Is video recording available?

Yes. AMCap supports recording as well as live streaming from connected capture devices.

### Can it save individual frames?

Yes. You can use the snapshot function to capture a still image from the active video source.

### Where are the configuration options?

Device and capture controls are managed within the application interface.
